# 功能、操作与数据边界

[返回首页](../README.md)

这里保留各视图的完整操作、统计口径、设置及资源边界。概览与支持来源见[首页](../README.md#支持范围)，插件包与生命周期见[架构说明](architecture.md#采集插件生命周期)。文中代码路径相对仓库根目录。

## 功能与统计口径

- **协作拓扑**：识别 OMP、Codex、Claude Code、OpenCode CLI 的存活进程，排除运行时内部 worker；Codex 桌面后台服务仅在持有当前会话时显示节点。合并包装进程，展示 PID、工作目录和可读取的模型元数据。OMP 同进程子代理通过当前打开的会话、ownership 描述符与父会话的专用 artifacts 目录关联；Codex 从可写 rollout 的会话元数据关联父线程。普通 fork 仍是主会话，独立子进程保留进程祖先关系与资源指标，同进程子代理不重复分摊资源。协作拓扑页面以可交互画布展示父子关系，概览仍提供简短列表。
- **定时任务**：读取用户及系统 launchd 配置、当前用户 crontab、OMP / Hermes 任务元数据。周期和日历任务计入定时数量，包含停用配置；常驻服务和启动项另列。OMP 配置与对应 launchd Label 合并，Hermes 内部任务与其调度器分开标注。支持类型、范围、状态和名称 / 执行计划的组合筛选；结果栏可随时清除已设置的筛选，恢复默认任务列表并将焦点放回搜索框。
- **系统监控**：从插件市场安装后采集 CPU、实际使用内存、应用／联动／压缩内存分项、交换空间、数据卷磁盘空间、默认网卡上下行吞吐及趋势。CPU 和内存各自从同一次完整进程采样中取前十，支持切换排序；内存排行按常驻大小（RSS），不是对 CPU 前十重排。最近 60 次 CPU／内存／网络采样只保存在内存中。
- **数据来源**：逐项展示可见范围、错误与最近成功采样时间。尚无成功采样时，等待与失败状态均显示数量未知；来源失败不转换成零。调度配置读取或解析失败会保留整个上次快照及采样时间并显示错误，只有运行状态读取失败时才保留已知任务并标记状态未知。暂停显示只冻结界面，后台继续采样；切换页面仍使用同一暂停时刻，继续显示时接收最新状态。

更新方式：当前归属的 OMP 会话通过文件事件订阅更新，按 90ms 固定窗口合并后增量读取，磁盘耗时另计。跨会话读取完成后按 16ms 固定窗口合并发布，后续事件不延长截止时间；只保留各会话最新结果，复用未变化的 Agent 对象，停止或移除会话时取消旧批次。Agent 进程、资源与归属每 2 秒独立发现，系统每 2 秒采样，调度每 30 秒采样；同类发现请求合并。IPC 只发送有变化的数据分区，自动采集不反复切换加载状态，系统采样不会重绘 Agent 页。

主窗与托盘分别登记数据和来源心跳订阅，主进程最多保留两个自有窗口登记。隐藏、最小化或暂停显示时停止相应窗口的监控推送和数据重绘，活动到期计时也冻结；后台采集继续运行，不积压隐藏期间的快照。恢复先订阅再读当前快照，新到分区事件优先于较慢的旧快照；显示窗口不会解除用户主动暂停。重载清除旧文档订阅，窗口销毁与应用退出释放登记和监听。无头开发允许按文档可见性验收，但始终禁止原生显示和聚焦。

数据来源页按实际来源展示进程识别、工作／空闲、父子关系、近期调用、精确活动数量、执行历史与跳转能力及限制。已连接、无数据、部分可见、失败、未支持和用户停用分别显示；OMP 活动子代理仍为未知，只有 CLI 进程证据时不推断正在工作。概览的未知数量与详情中的状态原因可定位对应来源。

来源行分别记录最近尝试和最近完整成功；无变化的采样只推送有界时间心跳，不重复发送任务或 Agent 列表。来源页离开、暂停或隐藏时解除时间订阅，恢复读取当前时间。失败的 launchd 域只重试该域；其它可重试故障明确标为“重试所属分区”，仅刷新相应分区。重复请求合并，等待时保留按钮焦点；正常有限覆盖和未支持不提供虚假的修复按钮。

「数据来源 → 脱敏诊断」先生成可查看和选择的完整 JSON 预览，显示字节数、纳入/总数及限制，再由用户复制或选择本地保存位置；不上传、不额外采集。只导出现有内存快照中的应用/系统版本、来源能力/状态、受控错误码与时间、资源额度计数和对象总数，不含用户名、UID、绝对路径、标题、命令、环境、凭据、正文或原始错误输出。来源ID归一化；无法完整统计的总数显示未知，不冒充0。

每份报告最多256KiB、64个来源、128条诊断和32项资源；超限与无效字段有明确省略说明。全应用只保留一个预览、一个在途操作和一个10分钟到期计时器；关闭预览、离页、窗口文档销毁或退出会取消并等待本实例操作释放。复制等待AppKit原生剪贴板确认；保存由Rust宿主调用系统对话框，0600权限临时文件完整写入后原子链接到新文件名，不覆盖已有文件或符号链接。取消/写入失败会清理本次临时文件，清理失败另报且阻止继续导出；成功写入后才显示成功。无头开发不弹系统保存对话框，文件事务通过受控选择器专项验收。

采集命令、文件读取与socket共用`crates/oc-core/src/resources.rs`的全局额度：各最多8个在途，stdout/stderr分别预留、合计最多32MiB；文件原始缓冲合计16MiB，socket合计512KiB。等待队列最多256项、每来源128项，来源标识最多32种；同类资源按来源轮转，较大请求保留其轮次，防止被持续小请求饿死。携带文件输入的命令原子申请命令与文件两类额度，跨类按入队先后保留所需容量，取消或超时解除等待优先权。排队最多10秒，获准执行后才开始各命令原有执行计时；队列满、超时或请求超额均明确失败。plist转换单流4MiB，launchctl单流8MiB。外部插件常驻进程和协议缓冲也计入全局账本，不长期占用一次性命令槽。

「数据来源 → 采集资源额度」显示当前槽位、字节预留、峰值、排队、拒绝数及排队/执行耗时；快照同时携带按来源拆分的只读数值。取消可移除未开始的请求；命令、文件和 socket 在真实关闭后才释放额度。文件用非阻塞打开并检查普通文件类型，拒绝命名管道/设备/目录占住读取槽位。长期文件监听不占短寿命读取槽位，仍受 128 会话上限约束。上述额度只计原始 IO 预留，不代表解析对象、缓存或全应用 RSS；长期压力验收由 R-04 单独跟踪。

停止监控先关闭入口并取消排队及在途采集，再等待文件、socket、监听器和本实例辅助子进程实际关闭；重复停止共享同一次排空，晚到结果不能发布。历史读取提供可等待的取消、idle 和 close。应用退出先拒绝新请求，等待窗口几何及已排队设置事务完成，再关闭仍可能被设置事务使用的采集插件和桌面效果；独立的导航、诊断和托盘同时清理。整个排空上限 5 秒；保存失败仍继续清理，失败或超时记录脱敏阶段、资源名及剩余额度，并以非零状态退出，不伪报释放成功。不会终止被观察的 Agent 或其它开发实例。通知随事件插件取消：停止接收批次、撤销未确认显示、关闭保留对象并解除电源监听；清理失败保留错误和有界句柄供重试，不能报告成功关闭。

默认网卡通过有界、可取消的 `route` 与 `netstat` 命令采样，只读取默认接口的链路计数，避免重复叠加地址行；首次采样、接口切换、计数器重置或读取失败后的首次恢复均显示速率未知，下一次连续成功采样后恢复速率。

CPU 差分基线、网络基线和最多 60 点历史绑定单个采集实例，销毁时清空。CPU 首次采样、计数回退或不连续时显示未知，下一次连续有效样本才显示数值；概览、系统页与托盘一致，走势图不会把未知值连到零。CPU 和 RSS 排行各最多 10 项。

调度目录用有界迭代读取：所有用户和系统目录合计最多 4096 个条目，包含被过滤的非 plist；配置、三个 launchctl 域、OMP、Hermes 与 cron 合计最多 4096 条任务、8 MiB 任务投影。来源记录最多 64 条、每条使用字段最多 4096 UTF-8 字节，日历条件及每条件字段各最多 64 项；公开任务标识长度限制同时生效。超限明确拒绝本轮，Monitor 保留上一完整快照及其时间，不将截断清单标为成功。

plist 原文件最多 1 MiB，通过普通文件描述符按初始大小分块读取，验证读取前后与转换后的身份，再把受限输入送入 plutil stdin；增长、替换或超限均拒绝。实例缓存按 dev/ino/size/mtime/ctime 失效，最多 4096 项、8 MiB（投影、路径键与固定元数据估算），单投影最多 64 KiB；删除文件回收额度，销毁清空。数据来源的「调度资源边界」显示扫描、任务和缓存额度，字节记账不等于 JS heap 或 RSS。

Agent 私有 host registry 枚举最多 4096 条（含非 JSON），超限不连接任何 host；最多读取 32 个 host、单记录 4096 字节，私有目录/文件权限、符号链接和真实进程身份检查继续生效。ownership 描述符及保留对象同样有合计数量和字段上限，错误不作为无活动证据；不扫描历史会话目录。

切换页面会保留本次主窗口会话的搜索、筛选、详情选择、页面滚动、系统进程排序及拓扑查看状态；返回时仍使用最新快照，失效对象清除选择并保留说明。搜索最多 1024 个字符。页面照常卸载，历史请求和页面监听随离页释放；不在后台挂载全部页面，也不缓存旧监控快照。重新加载或重启后恢复默认查看状态，已保存的外观与托盘组合不受影响。

左侧菜单栏可拖动右侧分隔线调整宽度：默认 214px，最小 188px，最大 320px；窄视口进一步收紧上限，为主内容保留至少 560px。Tab 聚焦分隔线后，可用左右方向键调整，Shift 加方向键加快，Home/End 到最小/最大；双击恢复默认，Esc 取消当前拖动。宽度自动保存，重启或重新加载后恢复已保存偏好。放大后的紧凑视口继续使用导航菜单，恢复宽窗时恢复所选宽度。

红绿灯右侧按钮或 ⌃⌘S 可隐藏／显示侧栏；隐藏后主导航与已安装插件成为顶栏标签，数据来源与设置固定在右侧，计数与来源问题数保留。向左拖过最小宽度 64px 也会收起，再次显示恢复拖动前宽度。顶栏变窄时标签文字收为图标，名称提示和无障碍名称保留，标签可横向滚动；760px 及以下改用紧凑菜单，快捷键开关菜单，不改写收起偏好。短 CSS 过渡遵循减少动态效果，不遮挡连续反向点击。

左侧一级导航只有一个「插件」入口：点击名称打开安装、更新与卸载管理页，旁边独立箭头用鼠标或 Enter／空格展开收起已安装插件，不改变当前页面。系统监控从「插件 → 系统监控」进入。目录随安装状态更新：未安装不显示，关闭采集仍保留，卸载后移除；正在查看的插件被卸载时回到「插件」管理页并聚焦标题。普通采样与页面切换保留折叠状态，主动进入插件页面会展开对应目录。未安装任何插件时显示空状态，名称入口在目录收起时仍可打开管理页；侧栏隐藏后顶栏保留一个同名「插件」入口和已安装插件页面，不额外显示「插件市场」。新市场插件通过共享目录中的 `distribution: 'marketplace'` 声明来源，并按插件 ID、采集分区和已安装状态进入子菜单；内置功能声明为 `builtin`。

### 协作拓扑画布

节点代表采集到的 Agent，箭头按 `parentId` 从父 Agent 指向子代理。同一个 PID 不会自动产生关系；父节点缺失或关系成环时显示明确提示，不生成虚构节点。

OMP 节点优先用当前会话标题显示简短工作摘要，最多两行；概览列表同步展示，悬停或详情可查看完整标题，也可按工作内容搜索。标题随正常进程发现更新，使用当前标题槽而非可能过时的初始标题；移除终端专用图标，不读取聊天正文生成摘要。未提供标题时保留 Agent 名称，详情明确显示缺失。摘要用于识别会话工作主题，不代表当前执行步骤。

Codex CLI 与桌面版的当前会话也进入同一画布：从存活 Codex 进程持有的可写 rollout 文件读取首条 `session_meta`，以线程 ID 标识节点，按 `source.subagent.thread_spawn.parent_thread_id` 连接同进程或独立进程子代理，显示可用的昵称、工作目录和会话开始时间。普通 fork 的 `forked_from_id` 不建立协作关系；父会话未进入当前采样时保留缺失提示，不创建虚假父节点。桌面后台服务只有持有会话时才产生节点。

Codex 不扫描历史目录、不解析会话正文；支持标准 `sessions/YYYY/MM/DD/rollout-…jsonl` 路径（包括自定义 `CODEX_HOME` 和带 rollout ID 后缀的文件）。OMP 与 Codex 每轮合计最多读取 128 个会话头部，Codex 每个头部最多 1 MiB；格式损坏、超限或重复归属显示读取不完整。关闭会话文件或进程退出后，下次进程采样移除对应节点。保留的可写会话不能证明仍在执行，Codex 子代理与桌面会话显示状态未知；尚未接入其近期调用、模型切换或外部窗口跳转。共享 PID 资源不重复计算，多主会话共享宿主时不猜测各会话占用。

概览里的具体 Agent 或任务可直接打开该对象的详情；“查看全部”仍只切换页面。托盘展开“查看 Agent 与任务”可打开各前五个对象或完整列表，来源限制也可直接定位到来源行。导航携带对象身份，重复通知和普通采样不会重放定位；首次加载通过读取后确认消费避免丢失目标。目标被筛掉时保留当前条件并提供“清除筛选并定位”，身份变化或对象离开时说明失效，不选相似名称的对象。关闭详情后返回该页对应节点/行；目标已不可见则返回搜索框。

默认使用 3D 项目建筑群：一个项目对应一栋楼，一个主会话及其真实父子分支对应一层任务。项目按根 Agent 的完整工作目录分组并忽略尾斜杠；同名不同路径分别成楼，不推测仓库根目录，未知项目单独成楼。主 Agent 位于独立玻璃办公室，子 Agent 在开放区域的连续共享长桌就座，跨工作目录的子代理仍归入主任务。缺父、循环或未确认主 Agent 的分支标为待归属，不生成虚假主 Agent 或办公室。任务名来自主会话摘要或名称，目前没有独立业务 taskId。选层会淡化其它任务、外立面和屋顶以观察内部；镜头不自动移动，可另用“聚焦楼层”。关系仍仅来自真实 `parentId`。

建筑坐落在井字路网划分的地块上，入口面向道路；人行道、路沿、树木和路灯提供空间参照。街区全景优先显示项目标牌，选中任务后再显示楼层细节。普通刷新和筛选保留存活项目的地块编号；主动点击“重新布局”会清除工位与地块位置，按当前可见项目紧凑排列。地景只表达布局，不表示真实地理位置或任务活动；没有车辆、人流或持续运动来模拟执行状态。

鼠标拖动空白处旋转，Shift 拖动平移，滚轮缩放；方向键平移，Shift 加方向键旋转，F 适应全部项目。主 Agent 只能在办公室内拖动，子 Agent 只能在本层开放工位区拖动；任务楼层菜单按项目分组，完整路径可在菜单提示中查看。建筑标牌聚焦项目，楼层和员工菜单、楼层标牌、可见员工支持定位及详情。工位、选层和镜头跨页面及 2D/3D 切换保留，重载后恢复默认；关闭详情后归还实际可见标签或画布的键盘焦点。员工标签优先于建筑和楼层标牌避让。不透明楼板／屋顶遮挡的员工不可被鼠标穿透选中；选层后的透明剖面仍可操作。

3D 单场景最多 1200 位员工、2400 条关系、400 万渲染像素、32 个员工标签、16 个楼层标签及16个建筑标牌；超限显示当前数量与限制，请调整筛选，不静默丢弃对象。员工和任务菜单可访问全部当前对象。图形上下文丢失提供重试；离页释放 WebGL、几何、监听器和标签。建筑、楼板和办公室共享几何并使用有界实例化网格。静止场景无持续动画循环，隐藏时停止绘制。按需加载 Three.js 0.187.0 的独立 chunk，生产渲染代码压缩，开发源包和类型依赖不进入应用包，原有包体积预算保持不变。

## 已知可见性边界

**目前不能准确报告 OMP 正在执行的子代理总数。** 完成后继续驻留的会话和lease不能证明仍在执行，应用保持“状态未知”和活动数`—`。2026-11-05已核对OMP18.16.0公开RPC、Collab与SDK：存在生命周期字段，但RPC面向其启动的会话，Collab元数据不含子代理清单，共享流又会同步正文，尚未满足既有本机会话的只读元数据接入边界。字段、身份和断线恢复缺口见[公开接口调研](omp-lifecycle-research.md)。本期不实施适配器，没有改OMP配置、注入进程或启用Collab。

Tern `inspect` 按实际窗口列表读取并精确关联主会话，提供主代理的 working/idle 证据；其他 CLI 只有进程活性证据时标“运行中”。头部模型是会话初始模型，不能当作始终准确的当前模型。OMP 自定义会话目录、隔离 profile、其他用户 crontab、容器及第三方应用内部调度不在现有覆盖内。

近期调用只读取当前归属会话中的结构化工具／模型事件，输出工具名、模型标识和时间等白名单元数据，不输出提示词、参数或结果正文。每文件读取上限 128 KiB、最多订阅 128 个会话；不扫描历史目录。完成、取消、错误或超过 6 秒会清除调用提示。长推理尚未落盘、历史窗口不完整与不支持的运行时都可能没有近期提示，不能据此判断空闲或精确活动子代理数量。监听／读取错误明确显示，文件替换在正常发现时重新挂接，没有轮询兜底。

macOS 存在带未公开 `StartCalendarInterval.Second` 字段的系统任务：应用保留任务与原值，并提示字段是否参与实际调度未确认。不会推算 launchd / cron 的下一次运行时间。

launchd 的服务表与禁用覆盖分别读取：`?` 和括号标记不被当作退出码，也不使整个域失效。失败按命令、权限、超时、表结构、行解析或资源上限分类，只输出固定诊断代码、来源、阶段和时间，不返回原始命令输出。每域保留最后成功时间；失败表的旧条目仅用于保留对象，不作为本轮状态或 PID 证据。单表最多 8192 项、单个名称最多 1024 字节，命令最多 6 秒及 8 MiB 输出；超限明确拒绝不完整结果。

`MonitorApi.retrySource(sourceId)` 支持当前用户的 `launchctl:gui/<uid>`、`launchctl:user/<uid>` 和 `launchctl:system`，只重读指定域的两张表并合并已缓存配置；重复请求合并，不扫描其他配置或刷新 Agent／系统来源。一次运行状态重试不能清除尚未恢复的配置读取错误。来源页展示逐项重试及能力说明；停用来源不允许重试。

标准 LaunchAgents / LaunchDaemons 配置目录使用类型和作用域组成的稳定来源ID（如`launchagents:user`）；自定义目录使用`launchdirectory:`加64位路径摘要，完整路径保留在来源标签中。深层工作目录不会把超长路径传进事件来源ID。目录尚不存在时标记为未配置的空来源，其他读取错误保留实际错误。前端能力识别、事件覆盖与脱敏报告均使用这一标识契约；脱敏导出只保留目录类型，不导出路径摘要。

任务范围中的“当前用户”表示运行域，包含在该域中运行的 Apple 系统任务；“个人配置”按来源识别 OMP / Hermes 内部任务、当前用户 crontab、用户 LaunchAgents 中的 `com.user.` / `local.` 命名配置，以及指向主目录脚本的任务。脚本入口识别支持直接执行、常见解释器及 Python 无参数开关；不解析内联命令，也不把任意参数里的脚本路径当作入口。系统任务、应用更新器和 Hermes 调度器自身不纳入个人任务。macOS 没有逐项创建者记录，此分类不是创建者认证；无法确认的任务仍可在“所有范围”查看。归类在采集端完成，仅输出归类值，不输出脚本参数或环境变量。

状态筛选与列表徽标保持一致：运行中、等待触发、已停用、未加载、状态未知。“未知”不等于停用，最近非零退出码也不自动改写当前运行状态；查看最近退出码可打开任务详情。类型、范围、状态和搜索共同过滤结果，不会执行、停用或修改任何任务。

Hermes 当前状态结合 `jobs.json`、`executions.db` 与进程证据：已启用且排程中、没有在途执行或未清理心跳的任务显示“等待触发”；执行记录为 running、心跳在 300 秒内且 PID 的启动时间吻合时显示“运行中”。有效运行证据优先于暂停配置。任务已领取但尚未开始、心跳过期、PID 复用、数据库不可读或未知调度状态都保留“状态未知”，详情说明原因；不会因上一次执行失败就改写当前调度状态。详情独立展示最近执行成功、失败、投递失败或结果未确认，以及结果记录时间；没有历史时显示暂无执行记录。

Hermes执行数据库由独立、短时Rust `oc-data-worker`以只读方式查询，使用随程序编译的SQLite，不依赖外部Node、Python或系统SQLite，也不触发任务或修改调度数据。任务元数据单文件上限1MiB；每轮最多256个任务，数据库内按真实时间、原始时间文本和执行ID确定性选择每个任务的最新记录，累计历史数量不作为状态可用性的门槛。子进程每个输出流上限4MiB，SQLite堆预算8MiB，获准执行后最多3秒，排队等待另计；取消等待worker及管道真实退出后才归还额度。超限或排序证据无效会明确报告采集不完整并保留未知状态，不截断后假称完整。采集与launchd查询并行，沿用每30秒刷新及同类请求合并。

任务详情从右侧展开，展示任务来源、执行计划、当前状态、配置路径及执行历史；点击整行或任务名称均可打开。历史按执行时间倒序，每页 25 条，支持刷新和前后翻页；每条显示执行结果、领取／开始／结束时间、耗时、执行 ID 和投递结果。执行记录中的“运行中”只表示数据库记录，不代表对应进程仍存活。

目前逐次执行历史接入 Hermes 的 `executions.db`。OMP、launchd 和 crontab 未提供该接口所需的逐次记录，详情明确显示来源不支持；这与 Hermes 的“尚无执行记录”、数据库读取失败分别表达。不会把最近退出码、计划配置或输出文件当作完整历史，也不读取提示词、错误正文、任务输出或聊天内容。

历史由任务插件显式注册 provider 并按需读取，最多一个在途请求和一个可替换的待处理请求。切换任务、关闭详情、切换页面、窗口隐藏或销毁时取消读取；重新显示后恢复。停用任务采集也会取消并等待历史子进程关闭，详情保留带采集时间的旧记录并禁止刷新／翻页；重新启用后重新读取，旧代请求不能覆盖结果。获准执行后最多 3 秒，等待全局额度另计且最多 10 秒；子进程每个输出流上限 128 KiB，SQLite 堆预算 8 MiB，请求偏移上限 100000。读取失败显示具体原因与重试入口；翻页失败可直接返回最近成功页，无需再次访问出错的数据库。

切页只保留历史页偏移和详情滚动位置，返回后重新读取同一任务的该页；记录变化导致该页为空时保留页码，提供上一页和返回首页。历史加载完成后恢复仍可到达的位置；用户主动滚动会中止待完成的恢复。返回的任务身份或页码不匹配时显示错误，取消后的晚到结果不会覆盖当前详情。

范围菜单按“配置来源”和“运行范围”分组，搜索使用当前界面显示的名称、来源与执行计划；英文界面的显示词同样可搜索。结果数量提供辅助技术状态播报，采样时间独立显示，不把暂停的快照描述成仍在更新。详情支持 Esc 或关闭按钮返回原任务；若原任务已被筛掉或移出快照，焦点返回搜索框。详情会说明任务已不在当前筛选结果中。键盘移向被详情遮挡的列表控件时收起面板并保留新焦点；翻页与重试将焦点移到执行历史标题。首次桌面数据连接失败时，任务区显示数据不可用与数量未知，避免一直停留在读取提示。

首次快照读取失败时，其他单个采样分区更新不会提前清掉整体错误；收到 Agent、调度、系统、事件四个分区，或完整快照 / 手动重试成功后才恢复。定时任务页点击重试会将焦点移到搜索框，错误提示消失后仍可继续键盘操作。

系统 CPU 是全机归一百分比；进程 CPU 按单核 100% 计，可能大于 100%。内存按 `Anonymous − Purgeable + Wired + Compressor` 页数计算，页大小从 `vm_stat` 读取。网络仅取默认接口，避免虚拟网卡重复计数。

## 本地异常事件

本地事件插件每30秒观察确认的 Hermes 执行失败、投递失败，以及数据源持续不可用和恢复。首次读取只建立历史基线，不把旧失败变成新事件；基线中最多128条未完成记录继续检查后续结果。来源须有新鲜、明确的错误证据持续60秒才记录不可用；停用、覆盖不足和超过120秒的采样间隔不推断任务失败。事件只保存固定标识、类型、发生／发现时间、结果代码与导航目标，不保存任务名称、参数、提示词、输出或错误正文。

Hermes 数据库始终只读；按数据库身份与 rowid 增量读取，轮转补查晚写入的结果，每次最多40条元数据，不以时间字符串作为唯一游标。七天范围之外、数据库替换、游标回退、未完成记录丢失和去重容量耗尽均保留覆盖断档。当前范围、排除水位及读取错误在「数据来源 → 本地事件」显示；事件插件停用会取消并排空其工作，重新启用恢复应用库中的游标。

应用自己的 `<userData>/events/events.sqlite` 使用0700目录、0600文件、原子事件／游标事务和稳定游标分页，每页最多50条，单条最多2KiB。保留期最多7天／10000条／20MiB（含日志），先到先清理并记录删除数量、截至时间与原因；主数据库上限8MiB、事件载荷3MiB，为索引和去重状态预留空间，DELETE journal与附属文件合计另受20MiB硬限制。最多16个存储请求、合计100条在途或排队事件，超过明确拒绝；有限子进程获准执行后最多3秒，SQLite堆16MiB，每个输出流256KiB。锁定、损坏、权限和空间不足明确报告，不重建或覆盖坏库。

已移除事件另保留最多32768条、最多7天的已处理标识。淘汰这些标识时原子推进排除水位，避免旧执行字段被改写后重复出现；代价是水位之前的后续变化不再补查，该排除范围写入持久覆盖断档。未淘汰范围内的同一执行和事件类型只记录一次，重启仍保持去重。本地通知默认关闭，与事件收集独立。

侧栏「事件」按精确来源ID、事件类型与发现时间筛选；编辑条件只修改草稿，点击应用后固定时间范围和分页上界。每页最多50条，分别展示发生与发现时间。后台发现新记录只显示提示并保持当前阅读位置；「刷新本页」沿用当前游标，「查看最新」才重新取最新上界。失败保留上次成功页和筛选，可重试原请求；离页、暂停和隐藏会实际取消查询，回来后读取成功页，不自动重放失败的翻页。

任务和Agent导航同时核对ID与身份；已消失或同ID身份变化时显示原标识及原因，来源导航沿用来源页失效说明。页面区分未启用、尚无保留记录、条件无匹配和读取失败；保留数量、删除范围与覆盖断档均标明读取时间，刷新才能重新核对该页信息。

## 本地通知

在「设置 → 本机通知」主动开启，选择来源或在Hermes任务详情订阅完整任务身份，再选择执行失败、投递失败、来源不可用／恢复类型。来源与任务任一匹配即可；取消来源不会移除单独任务订阅。整分区持续失败和实际来源都可订阅；cron／launchd没有逐次执行证据，不提供任务执行订阅。最多64个来源、24个任务，通知偏好最多48KiB，达到上限明确拒绝。

每滚动60秒最多显示3条（含摘要）；同来源和对象的连续故障冷却5分钟，恢复解除冷却。静默使用本地时间，支持跨午夜；时间编辑先保留草稿，再显式保存。静默、休眠和限流期间只保留计数，恢复后在下一轮事件采集汇总为一条，不回放所有旧通知。关闭通知或事件插件取消未完成工作并清除待汇总计数；事件列表继续按自身保留策略记录。

文案默认仅含OC Chan、事件类型与脱敏标识。显示任务名称需显式选择，并再次核对任务身份；不加入任务正文、私人路径或原始错误。点击才打开主窗口，复用现有目标身份校验；失效对象明确报错，摘要进入事件页。通知静音发送，不申请critical权限，不绕过系统专注模式；Rust适配器核对UserNotifications实际已投递列表后才记为已显示，系统接受发送请求不代表已显示，超时或失败标为未确认。

原生模块通过C ABI使用同一应用进程的UserNotifications权限。启动和普通刷新仅查询；只有用户按权限按钮才可请求授权。查询限2秒、显式请求限30秒、单条显示确认限3秒，整批限8秒。系统授权请求无法由应用强行取消：取消结束本次等待，但最多保留一个未完成OS请求，完成前拒绝新增请求并显示原因。系统异步回调持有受控共享状态，不能引用发起调用的栈变量。无头验收拒绝请求授权和发送真实通知；授权弹窗、实际投递/点击、专注模式及休眠唤醒须分别验收，查询成功不能代替这些证据。

去重日志保存在`<userData>/events/notifications.json`，上限64KiB，目录0700、文件0600、同用户且单链接；现有不安全权限、硬链接或损坏数据明确拒绝，不自动修复或清空。发送前持久认领事件序号，确认后再更新回执；崩溃后的未确认批次不重发，以避免重复，但可能少发，界面会标明未确认。事件数据库替换会明确重置身份游标。最多一个100条批次、64个冷却项、3个发送时间与8个原生通知对象；文件操作使用共享资源额度，未启用时不创建原生适配器、监听或日志。

## 设置

左下角“设置”打开同页平铺的设置。外观、语言、文字大小和托盘行为直接使用行内单选框，液态玻璃使用强度滑杆，主题使用带配色缩略图的单选卡片，两种字体使用下拉框，登录启动、程序坞与防休眠使用开关。保存后的设置即时生效，主窗口与托盘小面板保持同步：

- 外观：跟随系统、浅色、深色。
- 液态玻璃：0–100% 整数强度，默认65%；0%关闭。使用 Apple 原生材质，仅侧栏、顶栏和托盘外层露出玻璃，数据内容区保持实色。强度通过原生中性色遮罩与界面遮罩共同调整通透程度；AppKit 没有公开的折射或模糊半径调节接口。拖动实时预览，松开保存；键盘调整停顿250ms后保存。Esc、失焦、隐藏或离开设置页取消未保存预览。每次最多一个在途预览和一个可替换的最新值；预览失败恢复实色并提供诊断与重试，保存失败恢复已保存值。
- 系统启用“减少透明度”或“增加对比度”时，玻璃自动停用并保留强度偏好；关闭这些系统选项后恢复。系统不提供原生玻璃时明确显示不可用。
- 主题：OC Chan、GitHub、Nord、Catppuccin、Solarized、Gruvbox。参考 Tern 的配色缩略卡片，悬停或键盘聚焦可预览整个主窗口，点击或用方向键／空格选择后自动保存。离开选择区、按 Esc、窗口隐藏或离开设置页会取消未保存的预览；浅色与深色各自记住主题，跟随系统时自动使用对应配色。默认均为 OC Chan。
- 语言：跟随系统、简体中文、English；任务名和会话标题保留原文，设置诊断只展示受控元数据。
- 文字大小：12 / 13 / 15 px，按同一比例调整界面的文字层级；侧栏辅助说明与计数不小于 12 px。
- 界面字体：系统默认、PingFang SC、Helvetica Neue。
- 代码字体：系统等宽、Menlo、Monaco，用于路径、PID 与代码等宽内容。
- 点击托盘图标：打开菜单栏下的小面板，或恢复并聚焦主窗口。右键菜单始终提供打开主界面和退出。
- 菜单栏标志：使用 `resources/brand/oc-chan-mono.svg` 对应的 OC 单色品牌图形，22 × 18 点，提供 1× / 2× 位图表示；作为 macOS Template Image 适配系统菜单栏背景。
- 托盘面板：默认同时显示 Agent 与任务、CPU、内存、磁盘和网络的摘要；展开“显示内容”，可用复选框自由组合。每项指标可独立展开详情，多个详情可以同时打开；CPU／内存显示短时趋势及各自前五进程，内存有分项，磁盘显示数据卷容量，网络显示上下行趋势和实际接口名。组合保存在当前应用 profile 的本地存储中，关闭再打开、重载和重启后沿用；存储失败或无效组合会明确提示。折叠时不创建图表和进程榜；内容独立滚动，底部“打开主界面”固定可达。隐藏时停止面板数据订阅，重新显示时获取最新快照；后台采样继续。
- 托盘窗口按需创建：手动启动只创建主窗口，登录启动只保留菜单栏图标；首次请求面板才加载托盘页面。连续请求共享一次加载。页面加载与绘制就绪后再展示，超过10秒或加载失败会释放窗口并报告错误，下次点击可重试。正常隐藏保留已创建面板，退出时取消在途加载并释放资源。无头性能验收仅在开发配置中显式创建隐藏托盘，不增加正式IPC入口。
- 登录后启动：仅安装在“应用程序”文件夹中的 macOS 应用可修改自身的系统登录项。首次运行不自动注册；开关读取 macOS 实际状态，系统设置中的禁用不会被本地偏好覆盖。等待批准时保持未开启并提供取消请求；在系统设置中批准后可重新检查。登录启动不创建主窗口、不显示 Dock、不自动防休眠，仍可通过菜单栏打开界面。开发/无头实例禁止注册。
- 显示程序坞：控制 macOS Dock 图标；关闭主窗口后仍在菜单栏运行，可重新打开。
- 防止休眠：运行期间阻止空闲休眠，关闭设置或退出应用时释放。不会阻止屏幕熄灭、合盖或手动休眠。

常规窗口按“设置名称 + 控件”排列；设置内容宽度不超过 560px 时，每项改为名称在上、控件在下，应用更新和偏好仍在同一页纵向滚动。主题卡片随设置容器宽度从三列调整为两列或一列。放大后主导航收进菜单，设置控件不会被替换或隐藏，焦点保持在原控件。

Agent 活跃状态、任务范围／状态和两项字体设置的下拉框使用统一箭头留白；中英文、深浅色及最小窗口 200% 缩放下保持箭头居中与文字避让，仍使用原生选择菜单。

侧栏宽度和收起状态自动保存在同一设置文件中：拖动松开时保存，键盘调整稳定250ms后保存，双击恢复214px也会保存；Esc、失焦或隐藏取消正在进行的拖动。宽度偏好严格限定为188–320整数CSS像素；窄视口可以临时限制实际宽度，扩大视口后恢复已保存偏好，不将临时限制写回。收起保存失败时恢复最近实际设置，并在当前页显示“侧栏布局”保存错误与重试；快速切换以最新意图排队，较早回执不覆盖待保存布局。

主窗口保存正常态外框位置与尺寸（macOS逻辑坐标，与页面文字尺度、页面缩放和物理像素分开）。连续移动/缩放延迟250ms合并，最多一个在途和一个待写入值；退出时等待最后一次写入。重启按当前屏幕工作区限制尺寸和位置，显示器移除后重新定位；不恢复最小化、最大化或全屏状态。仅几何变化不会重建原生菜单或重新应用Dock/防休眠。侧栏和窗口保存失败在当前页面显示原因与重试，窗口本身保持当前几何，但不会声称未写入的值已保存；无头开发实例始终不显示或激活窗口。

登录项由macOS保存，不向`settings.json`添加第二份开关。回到设置页、窗口重新获得焦点或点击“重新检查”时读取真实状态；失败显示脱敏诊断，写入部分成功时尝试还原。还原失败仍显示实际状态并要求核对系统设置，不伪报保存成功。原生桥接使用`SMAppService.mainAppService`和应用启动事件辨认登录启动；开发模式拒绝登录项变更。真实安装注册、系统批准与隔离账号登录尚待原生专项验收，开发夹具通过不代表这些场景已通过。

### 设置文件

偏好保存在应用用户数据目录的 `settings.json`，文件中的有效设置覆盖应用默认值，未配置项使用默认值；显式无效的值、未知字段及损坏 JSON 均报错。读取以 `O_NOFOLLOW | O_NONBLOCK` 打开，同一描述符核对普通文件，分块读取且最多64KiB；拒绝目录、FIFO、符号链接、读取期间增长或改变的文件，以及无效UTF-8。缺失文件仍是合法首次启动，损坏文件不会自动替换。保存串行执行，以0600独占临时文件写入、同步、关闭后原子替换；原生操作或写入失败时恢复原设置，回滚失败明确报错并退出。关闭、清理失败保留在错误链中。保存期间保留控件焦点，阻止重复提交；悬停预览不写入文件。

保存失败会在对应设置行下方说明路径冲突、权限不足、空间或配额不足、只读文件系统、超时等原因，展示本地完整设置路径与恢复步骤，排除故障后可重试同一修改。复制区使用 `src/shared/diagnostics.ts` 的白名单摘要，与主进程启动/退出日志共用出口：仅含允许的错误类型、代码、数值errno、失败阶段及受控元数据；设置资源表示为 `<appData>/settings.json`，不回显原始message、stack、stderr、命令或正文。错误链最多8层、16条、16KiB，循环/重复引用、深链、条目或字节超限、无法安全读取的字段会明确标记截断。若保存确认中断，则明确标为“保存结果未确认”，保留最近收到的实际设置，不将其误报为未保存。

手工修复前先在原路径之外备份。文件必须是 UTF-8 JSON 对象，最多64KiB；只允许下列字段，合法的缺省字段使用默认值，未知字段和非法值不会被忽略或迁移：

- `appearance`：`system`、`light`、`dark`；`language`：`system`、`zh-CN`、`en`。
- `lightTheme`、`darkTheme`：`oc-chan`、`github`、`nord`、`catppuccin`、`solarized`、`gruvbox`。
- `glassIntensity`：0–100的整数，默认65；0关闭，非法值直接报错。
- `textSize`：`small`、`default`、`large`；`uiFont`：`system`、`pingfang`、`helvetica`；`codeFont`：`system`、`menlo`、`monaco`。
- `trayClick`：`tray`、`main`；`showDock`、`preventSleep`、`sidebarCollapsed`：JSON 布尔值；`sidebarCollapsed` 默认 `false`。
- `sidebarWidth`：188–320的整数；`windowBounds`：`null`或只含整数`x`、`y`、`width`、`height`的对象，坐标绝对值不超过131072，宽320–16384、高240–16384。实际恢复还受当前屏幕工作区约束。
- `plugins`：只允许 `agents`、`schedules`、`system`、`events` 四个 JSON 布尔字段，缺省均为 `true`。补丁按子字段串行合并；未知 ID 和非布尔值直接拒绝。全应用最多接受16笔设置事务（含在途），超出报告 `OC_SETTINGS_BUSY`。

### 启动恢复

可见应用读取设置失败时暂停正常启动，显示系统语言和系统明暗模式下的恢复页面。页面分别说明损坏 JSON、非法字段/选项、无效编码、超限、权限或文件路径问题，提供完整本地路径、人工修复步骤及可选择复制的脱敏诊断。不会改动原文件、重置偏好或应用部分无效设置；恢复期间采集尚未启动。

“重新读取”只访问固定的设置文件，并发请求共用一次有界读取。失败保留恢复页面并更新原因；文件合法后仅启动一次主界面与采集，撤销恢复接口并销毁恢复窗口。macOS在窗口交接间隙继续运行；关闭恢复窗口或选择“退出 OC Chan”则等待在途读取结束后退出，不会因迟到结果恢复启动。无头开发遇到相同故障只输出受控诊断并失败退出，不创建恢复窗口。首次缺失设置文件仍正常使用默认值。
