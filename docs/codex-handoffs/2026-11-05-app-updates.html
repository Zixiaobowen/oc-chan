更新时的行为

签名安装版启动 30 秒后、之后每 6 小时检查公开安装包仓库。设置页也可手动检查；发现新版后提示，由你决定下载。下载完成后点击“重启并安装”，原生更新器校验签名并交接安装。

普通退出不安装，并清理临时包。开发模式及未签名包会显示原因。源码保持私有，客户端不保存 GitHub 令牌。
