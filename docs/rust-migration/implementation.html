隐藏页面的绘制调度

WKWebView 可能暂停隐藏文档的 rAF。无头模式显式使用可取消的单次任务执行真实 Three.js 绘制、标签投影、2D 测量及滚动恢复；普通窗口继续使用原生 rAF。实际 WebGL 调用和原生动画回调分别计量，不把任务回调或布局刷新称为显示帧。

测试进程的真实祖先

直接从 OMP 工具启动的四个夹具都存在真实 OMP 祖先，因此采集器将它们识别为子任务。夹具改由短命启动器创建，并在实际 PPID 变成 1 后就绪。生产父子关系规则保持依据真实进程和会话证据。

错误与工具链

修复了来源诊断的非法枚举及早期原生初始化问题；市场错误断言检查稳定错误码。工作区固定 Rust 1.99，解决本机 macOS 对旧 release 动态库 LINKEDIT 布局的拒绝。失败报告保留，不覆盖原始结果。

键盘证据范围：实际WK偏好tabFocusesLinks=true，隐藏文档document.hasFocus=false；原生Tab没有触达目标。控件激活与保存验收使用显式DOM聚焦后发送真实AppKit按键，不作为可见窗口Tab导航或焦点环通过的证明。
