## 1. 优先级、状态与当前事实

- **P1**：当前缺陷、可靠性/安全硬边界，或未来正式分发前必须满足的条件。优先级不消除前置依赖；延期的正式分发门槛不阻塞本期本地使用。
- **P2**：补齐日常使用价值、扩展能力和维护性；基础可信后实施。
- **P3**：依赖上游能力或真实试用反馈的后续项。
- **可派发**：当前没有硬依赖；**待依赖**：前置卡尚未完成；**外部条件待核实 / 外部阻塞 / 外部协作待安排**：只推进本期范围内不依赖该条件的工作；**延期（本期不实施）**：不安排实施、凭据准备或外部联系，恢复日期未定。上述状态均不等于整卡完成。
- “已实测缺陷”“源码缺口”“历史记录缺陷”“新增建议”“待验收”是证据类型，不是实现进度。没有证据时不称为已证实漏洞。

## 3. 所有任务共用的交付契约

1. 实施前读取当前卡、用户范围决定（本地记录：`docs/codex-handoffs/2026-11-04-owner-scope-decisions.md`，不随仓库分发）、直接依赖和当前代码。按用户要求串行执行本期工作，每项验收后再进入下一项。保留用户/并行改动；大规模重构使用独立分支。隔离工作区必须包含本批认可的当前实现，不能从旧HEAD启动后遗漏未提交功能。
2. 本机只读观察边界：不运行/停用任务、不杀Agent、不读聊天/提示词/命令/环境/任务输出正文、不改上游运行时配置。缺数据、0、空结果、未支持、用户停用、失败要区分。
3. 新接口只保留一条实现路径；更新全部调用方和受影响测试/文档，删除被替代路径。无兼容层、migration、fallback；错误不能吞掉。对缺失可选字段的合法默认与错误恢复不得混为一谈。
4. 新依赖先证明现有依赖不能完成，并记录运行时/开发时用途、依赖树与包体积增量。生产包不包含测试、缓存或个人数据。
5. 实现子代理不在中途跑build/lint/tests/formatter，返回应运行的定向命令与未确认项。主代理集成后只跑相关模块/调用方检查和真实smoke；新增测试必须验证消费者可见的行为/边界，不能只测接线、文案或mock回声。
6. 自动化默认 `npm run dev`，独立profile/构建/端口；只停止本任务实例。若npm包装缓冲日志，使用同一启动器 `node scripts/develop.mjs`，不换裸Electron入口。只有后续明确安排原生交互专项时使用 `dev:window`；headless证据不冒充Dock/物理托盘/VoiceOver/原生焦点/可见动效通过。
7. 功能卡完成必须有端到端行为；验证卡完成必须有实际证据。每卡分别记录代码、定向检查、真实应用、安装包、外部服务状态，不互相替代。任务状态由“待执行”变“已完成”时补证据链接和未覆盖范围。
8. 发布、安装替换、Apple公证、外部联系、远端配置按对应授权执行。本期范围内的外部条件欠缺时完成可准备内容，保留明确阻塞，不标整卡完成。D-01/O-01已明确延期，不因此继续安排凭据核查、配置草案或招募；安装及原生专项仍须对应授权。

### 性能负载与预算口径

以下是待执行的验收负载和**建议起始目标**，不是当前成绩。P-01必须产出实测基线和绝对RSS预算；调整建议值需记录理由，不能在失败后悄悄放宽。

| 负载 | 输入与行为 |
| --- | --- |
| L0 空闲 | 正常真实来源，无新增会话事件；主窗/托盘分别显示及同时隐藏 |
| L1 日常 | 32个合成当前会话，每会话每秒1条白名单元数据；1000个plist；切页/筛选/任务历史，每分钟变更10%配置 |
| L2 边界/突发 | 128会话每秒10条事件，最多60秒突发；100次并发刷新；200个历史替换请求；4096/4097配置；128/500/2000拓扑节点；超长记录/锁库/超时 |
| L3 常驻 | 24h确定性循环：稳定采集、对象换代、页面切换、插件启停、错误注入；按已实现功能追加事件/通知负载 |

- 采集资源：建议命令/活动文件读/socket分别并发8；命令双流缓冲合计预留32MiB。SQLite/V8配置不是RSS上限；对象、缓存、DOM与IPC副本单独计。
- 建议响应目标：L1事件→渲染p95≤250ms/p99≤500ms；200节点布局p95≤50ms、选择反馈p95≤100ms；首次托盘p95≤500ms。硬件/冷缓存/慢磁盘差异须报告。
- 稳定性：完整应用进程树，包含短命辅助进程；开发server另列。必须同时检查绝对预算、逐小时趋势、资源回落和无OOM，不能仅看JS heap或短时平均。
- 合成数据和原始采样只放隔离临时目录，不污染生产源；负载生成/采样器自身同样有数量、字节与取消上限。
